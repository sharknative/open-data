# Wellness Rundown: Small-Space Fitness Index

Size, ceiling-need and weight-limit data for 29 compact fitness machines (walking pads, folding treadmills, bikes and similar), one row per machine. In `small-space-index.csv` each measured value has a value column, a unit column, a source URL column and a quote column. In `small-space-index.json` each cell is an object with `value`, `unit`, `src` (the URL), `quote` (the phrase on that page) and `src_type` (maker, manual or listing). The file also holds the space-score formula and its parts per machine.

Source and latest version: https://wellnessrundown.com/small-space-index/

How the data was gathered: maker product pages and manuals, each cell cites its URL; cells with no published figure are left blank. From the page: "Every value is copied from the maker's product page or manual (src_type maker/manual), or from Amazon's product data when the maker has no product page (src_type listing). Blank = not published. Nothing here was measured by Wellness Rundown." Where a cell's source is a retail listing, the source URL is the plain product page, with no tracking parameters.

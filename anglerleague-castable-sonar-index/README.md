# AnglerLeague: Castable Sonar Spec Index

Spec table for 11 castable fish finders, one row per unit: screen or app, weight, rod fit, cast range, depth, beams, battery, GPS mapping, app terms, the source each row was read from, a bank-fishing score with its parts, a note and the date checked. This dataset cites the source per row (`source` column) rather than per cell. `castable-sonar-index.json` holds the same rows plus the score formula and the check date.

Source and latest version: https://anglerleague.com/castable-sonar-index/

How the data was gathered: maker product pages and manuals, each row cites its source; cells with no published figure are left blank. From the page: "Every cell is from a maker page, Garmin's owner's manual or, for Venterior and LUCKY, the Amazon listing text, all read October 21, 2026." The page also states it is a spec comparison, not a fishing test.

Open product spec tables

Six small tables built from maker-published specifications. Every cell was read from the maker's product page or manual and cites that URL; a blank cell means the maker does not publish the figure. Nothing here was measured or tested by hand. Each table's canonical, latest copy lives on its page.

Automatic litter box spec table

VettedFur · 18 rows · CC BY 4.0

Self-cleaning litter boxes: entry, height, cat weight, footprint, drawer, app, refill cost.

Latest copy: https://vettedfur.com/data/automatic-litter-boxes/

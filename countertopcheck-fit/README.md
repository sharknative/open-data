# CountertopCheck: appliance heights and cabinet clearances

Published heights, in-use heights and manual clearances for 59 countertop appliances (stand mixers, blenders, toaster ovens, ice makers, bread machines and more). One row per appliance. In `fit.csv` each row carries the closed height, width, depth, the clearance the manual asks for above the appliance, the resulting height needed, a caveat, the source URL and the date checked. In `fit.json` each measured cell is an object with `v` (the value, in inches; lb for weight) and `u` (the maker page or manual URL the value was read from).

Source and latest version: https://countertopcheck.com/fit/

How the data was gathered: maker product pages and manuals, each cell cites its URL; cells with no published figure are left blank. From the page: "Every number is quoted from the maker's page or manual (or a named retailer spec tab where the maker blocked access); a missing number is not published."

# VettedFur: automatic litter box spec table

Spec table for 18 self-cleaning (automatic) litter boxes, one row per model. In `automatic-litter-boxes.csv` every spec column is paired with a `*_source` column holding the maker page it was read from (26 columns). In `automatic-litter-boxes.json` each box carries its values with the source URL and the exact phrase on that page; a blank or `null` cell means the maker does not publish that figure.

Source and latest version: https://vettedfur.com/data/automatic-litter-boxes/

How the data was gathered: maker product pages and manuals, each cell cites its URL; cells with no published figure are left blank. From the data file: "VettedFur automatic litter box spec data, as of 2026-10-21. One record per box in the table at https://vettedfur.com/data/automatic-litter-boxes/. Every spec cell is {v, url, q}: the value shown, the maker page it came from and the exact phrase on that page. null = the maker does not publish that nu"

# CremaCheck: office espresso machine data

Office capacity, cleaning and warranty data for 12 espresso machines, one row per machine. In `office-machines.csv` every spec column (tank size, hopper, grounds capacity, milk system, shot and dose size, daily and weekly cleaning steps, descaling interval, office warranty terms, office-use statement) is paired with a `*_source_url` column holding the maker manual, spec page or warranty page it was read from. `office-machines.json` holds the same machines with each cell as value, source URL and the quoted phrase from that source.

Source and latest version: https://cremacheck.com/office/

How the data was gathered: maker product pages and manuals, each cell cites its URL; cells with no published figure are left blank. From the page: "every cell quoted from the maker's manual, spec page or warranty."
